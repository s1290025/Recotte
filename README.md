# Recotte! | レコッテ！

本と感想を残す、シンプルな読書記録アプリです。ログイン不要・ビルド不要です。

## できること

- Google Booksでタイトル・著者・ISBNを検索して登録（APIキー設定が必要）
- 手動での登録、タイトル・著者の修正
- 読みたい / 読書中 / 読了の管理
- 読了日・感想の記録、編集・削除
- 記録の検索・絞り込み
- JSONバックアップの書き出し・読み込み（既存記録に追加し、同一IDは確認後に上書き）

## GitHub Pages

リポジトリの **Settings → Pages → Build and deployment** で、以下を選択して Save します。

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

公開先: https://s1290025.github.io/Recotte/

## データ保存

記録は利用中のブラウザのlocalStorageに保存します。端末・ブラウザを変えても自動同期しません。サイトデータを削除すると記録も消えるため、定期的に「書き出し」でバックアップしてください。バックアップを別のブラウザで読み込むこともできます。

読書記録はGitHubに送信しません。書籍検索語はGoogle Booksへ送信し、表紙画像は外部サービスから読み込みます。検索APIが利用制限等で失敗した場合も手動登録は利用できます。

## ローカルで動かす

このディレクトリで `python -m http.server 8000` を実行して http://localhost:8000 を開きます。

## Google Books APIの設定

現在はGoogle Booksを検索元に使用します。利用者のGoogleログインは不要です。

1. https://console.cloud.google.com/ で Recotte 用のプロジェクトを作成または選択します。
2. 「APIとサービス → ライブラリ」で Books API を有効にします。
3. 「APIとサービス → 認証情報」でAPIキーを作成します。
4. アプリケーションの制限を「ウェブサイト」にし、https://s1290025.github.io/* を許可します。APIの制限は Books API のみにします。
5. Recotte! の「＋ → 検索設定」にAPIキーを入力して保存します。
6. タイトル・著者名・ISBNで検索し、結果から本を選択して登録します。

キーはこのブラウザのlocalStorageだけに保存し、GitHubやバックアップには含めません。キーはチャットや公開リポジトリに貼り付けず、アプリの設定欄に入力してください。APIへは X-Goog-Api-Key ヘッダーで送信します。

この構成は個人用の試作向けです。一般利用者への公開で共通のキーを使う場合は、キーの管理・利用上限を含めた構成を別途検討してください。

キーはまだ設定されていません。有効な設定後に実際の検索と表紙表示を確認してください。未設定でも手動登録は利用できます。APIキーを設定しても利用上限やデータ欠損がなくなるわけではありません。

検索結果は10分間メモリ内に保存します。ISBNは全角・ハイフン入りも正規化して検索し、タイトル・著者検索は言語を限定しません。表紙は返却された画像URLを順に試します。情報がない本は手動登録してください。

公式仕様: https://developers.google.com/books/docs/v1/using
