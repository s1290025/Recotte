# Recotte! | レコッテ！

本と感想を残す、シンプルな読書記録アプリです。ログイン不要・ビルド不要です。

## できること

- 楽天ブックスでタイトル・著者・ISBNを検索して登録（開発者によるAPI設定が必要）
- 手動での登録、タイトル・著者の修正
- 読みたい / 読書中 / 読了の管理
- 読了日・感想の記録、編集・削除
- 記録の検索・絞り込み
- JSONバックアップの書き出し・読み込み（既存記録に追加し、同一IDは確認後に上書き）

## GitHub Pages

リポジトリの **Settings → Pages → Build and deployment** で、以下を選択して Save します。

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

公開先: https://s1290025.github.io/Recotte/

## データ保存

記録は利用中のブラウザのlocalStorageに保存します。端末・ブラウザを変えても自動同期しません。サイトデータを削除すると記録も消えるため、定期的に「書き出し」でバックアップしてください。バックアップを別のブラウザで読み込むこともできます。

読書記録はGitHubに送信しません。書籍検索語は楽天ブックスへ送信し、表紙画像は外部サービスから読み込みます。検索APIが利用制限等で失敗した場合も手動登録は利用できます。

## ローカルで動かす

このディレクトリで `python -m http.server 8000` を実行して http://localhost:8000 を開きます。

## 楽天ブックスAPIの設定

1. https://webservice.rakuten.co.jp/ で楽天アカウントにログインし、アプリを登録します。
2. アプリ名は Recotte!、アプリURLは https://s1290025.github.io/Recotte/ を指定します。許可するウェブサイトにも実際の公開元を登録してください。
3. 発行されたアプリIDとアクセスキーを用意します。APIサンプル掲載のキーは使わないでください。
4. Recotte! の「＋」→「楽天API設定」に入力し、保存します。この設定は利用中のブラウザだけに保存し、読書記録のバックアップには含めません。
5. タイトル・著者名・ISBNを選び、検索します。ISBNの10桁・13桁入力は自動判定します。

サイト全体で共通の設定を配布する場合は index.html の RAKUTEN_CONFIG を開発者が設定します。GitHub Pagesのコードや通信内容は閲覧できるため、ブラウザ向けに利用できるアクセスキーを使い、楽天側で許可サイトを限定してください。サーバー専用の秘密情報は配置しないでください。

アプリID・アクセスキーはまだ設定されていません。有効な設定を入れるまでは手動登録を利用できます。実際の検索・表紙表示は有効な設定後に確認が必要です。楽天の利用条件に従い、検索画面に指定のクレジットを表示しています。

タイトル・著者名・ISBNの検索、表紙・著者・出版社・発売日・ISBNの取り込みに対応します。品切れ・販売終了の商品も検索対象に含めますが、楽天の収録情報がない本や表紙がない本は取得できません。検索結果は10分間のメモリキャッシュで再利用します。

公式仕様: https://webservice.rakuten.co.jp/documentation/books-book-search
